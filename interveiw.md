# Interview Questions

## 1. What is FastAPI?

FastAPI is a modern, fast (high-performance), web framework for building APIs with Python 3.7+ based on standard Python type hints.

## 2. What is an API.?
Api is a bridge that connects front-end to backend. frontend request send karta hai aur backend response bejta hai.

## 3. What is Route, Route kaya hota hai.?
Route aik url path hota hai. jaha specific function ko execute karty hain based on their path.
